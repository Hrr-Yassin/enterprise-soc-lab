# Detection coverage

Every scenario has a targeted negative control. A pass requires the target rule in an indexed positive alert and an archived manager record for the corresponding control. Other stock informational alerts may be present. Rule severity is the Wazuh alert level. Case severity additionally considers confidence, impact, and scope.

| ID | Objective and telemetry | Rule and expected alert | Control, likely false positives, and analyst response |
| --- | --- | --- | --- |
| D01 | Detect repeated failed SSH authentication from one source. Syslog-format fixture records use the SSH decoder. | Stock 5763, level 10. Eight failures in 120 seconds for the same source IP. [T1110.001](https://attack.mitre.org/techniques/T1110/001/) | Seven failures from a separate address. VPN gateways, shared NAT, and stale credentials can group unrelated activity. Check the source, targeted account and any subsequent successful authentication. Confirm intent before enforcing a block or resetting credentials. |
| D02 | Detect an addition to local Administrators. Windows Security 4732 fixture with target group SID. | 100102, level 11, matches S-1-5-32-544. Native channel candidate 100122. [T1098.007](https://attack.mitre.org/techniques/T1098/007/) | A change to standard Users. Compare actor, member and ticket for planned helpdesk work. Verify group membership and revert unauthorized elevation with the owner. |
| D03 | Detect an administrative denial. Native Auditd USER_CMD from the Linux guest. | 100103, level 8, matches a failed command authorization by the sudo executable. [T1548.003](https://attack.mitre.org/techniques/T1548/003/) | Authorized no-op sudo. An operator mistake or missing delegation can cause denial. Confirm account, command and host context. Review delegation and watch for successful elevation before escalating. |
| D04 | Detect a change to the monitored inventory file. Native Wazuh FIM hashes and path. | 100104, level 9, matches inventory.txt under the scoped directory after stock 550. | Modify notes.txt. Version updates can be legitimate. Compare hashes and approved changes. Restore a known version if needed and preserve who changed it through independent evidence. |
| D05 | Detect transient systemd jobs outside the lab inventory naming policy. Native systemd syslog. | 100105, level 8, matches a lab job start with a name outside the inventory prefix. [T1543.002](https://attack.mitre.org/techniques/T1543/002/) | A transient inventory job. New maintenance jobs may be approved. Inspect the unit, parent action and ticket, and verify whether it can recur before disabling anything. |
| D06 | Detect an executable started from a shared writable Windows location. Sysmon ProcessCreate fixture. | 100106, level 8, covers .exe files directly under the Public profile. Native channel candidate 100126. | Same executable name in Program Files. Portable authorized tools can trigger the rule. Check signature, hash, parent, and user. Limit execution from writable locations where policy supports it. A path alone does not establish an ATT&CK technique. |
| D07 | Recognize the lab's disallowed DNS namespace. Live Suricata EVE on guest loopback. | Sensor 9900101 and Wazuh 100107, level 7. Alert includes signature and flow reference. | Query the allowed .soc.test namespace. New internal naming can trigger this policy. Compare query, resolver and client with approved inventory. A suffix match does not establish tunneling or exfiltration. |
| D08 | Identify a packet delivered to a disallowed lab UDP port. Live EVE alert. | Sensor 9900102 and Wazuh 100108, level 8. Destination 15941 in the lab capture scope. | Approved port 15940 generates an informational control record. Check the flow direction, application owner and policy. The passive sensor does not enforce the rule. |
| D09 | Detect a change to the monitored service policy file. Native Auditd syscall and path records. | 100109, level 9, requires a successful operation using the soc_policy_change watch key. | Read the service policy and separately write the watched control file to prove Auditd receipt. Approved deployment or permissions maintenance is expected noise. Consult the audit serial, process and actor before comparing the current file to the baseline and restoring it. |
| D10 | Detect a denied export request by a service identity. Test application authorization log. | 100100, level 8, requires service, export action, service principal and a deny decision. | Health request by the same service identity. A stale token or route misconfiguration can trigger denial. Compare service deployment and permission changes, confirm data scope, and verify that the request returned no records. |

D02 and D06 use labeled fixtures. They verify the box that detects and indexes their event shapes. They do not validate the Windows transport or grant a Windows host coverage claim. Live results and exact alert references are recorded in the run evidence.
